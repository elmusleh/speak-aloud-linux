# Changelog

## 2026-11-09

- **Reorderable Buttons, HUD Transparency, Audio Sink Selector & System Integrations (`tts_hud.py`, `tts-settings.py`, `tts_text_processor.py`, `speak.sh`, `tts_synth_worker.py`, `tts_ocr.py`)**:
  - **Reorderable Tools Drawer**: Added dynamic drawer tool reordering inside Settings Studio (`QListWidget` with Move Up/Down controls) and live layout reordering via `hud_drawer_order` in `FloatingPlayerWindow`.
  - **HUD Opacity & Transparency Slider**: Added slider in Settings Studio (50% to 100%, default 95%) with automatic 100% opacity boost on hover (`enterEvent`/`leaveEvent`).
  - **Custom Keyboard Hotkey Remapper**: Added single-key shortcut remapper in Settings Studio mapping custom hotkeys (`transcript`, `bookmark`, `anki`, `queue`, `ocr`, `sleep`, `more`, `stop`) saved to `custom_hotkeys`.
  - **Profile Switcher Shortcut (<kbd>Shift+P</kbd>)**: Quick keyboard shortcut to rotate between Minimal, Reader, Productivity, and Default HUD button profiles.
  - **Audio Output Device Selector**: Added audio device switcher button and menu in More Tools Drawer querying PipeWire (`wpctl status`) and PulseAudio (`pactl list short sinks`), switching default output sink on demand.
  - **Gapless Segment Audio Crossfading**: Added `--gapless-audio=yes --audio-stream-silence=yes --audio-buffer=0.25` in `speak.sh` for seamless inter-segment playback.
  - **Battery & AC Power Awareness**: Added battery detection (`/sys/class/power_supply/BAT*/status`), throttling background synthesis workers when running on battery to conserve power.
  - **Desktop Notification Transport Actions**: Added interactive action buttons (`--action="pause=Pause" --action="stop=Stop"`) to desktop speech notifications.
  - **Automatic Text Punctuation Restorer for OCR**: Added `restore_punctuation_for_ocr` pass healing missing trailing periods, detached commas/question marks, and capitalizing lines for natural voice cadence.
  - **Spoken Reading History Log & Exporter**: Added JSONL session logger (`record_spoken_history`) and one-click Markdown and CSV export in Settings Studio.
  - **Async Synthesis Server Hardening**: Added `MAX_MESSAGE_BYTES = 1MB` payload cap and sliding-window rate-limiting in `AsyncSynthServer`.
  - **Wayland Native Screen Selection Fallback**: Added `slurp` + `grim` fallback in `tts_ocr.py` for Wayland desktop sessions.
- **Popup Buttons Management Tab in Settings Studio (`tts-settings.py`, `tts_hud.py`, `tts_text_processor.py`)**: Added a dedicated "Popup Buttons" tab in the Settings Studio allowing users to toggle and customize exactly which transport controls and action buttons appear in the Floating Player popup. Includes 4 one-click presets (**Minimal**, **Reader / Study**, **Productivity**, **Enable All**), individual control over all primary and drawer buttons, automatic drawer toggle hiding when all tools are disabled, and instant dynamic reload of button visibility on save without restarting the daemon.
- **OCR Lifecycle & Screen Font Preprocessing Fix (`tts_ocr.py`)**: Fixed `RegionOverlay` Qt window lifecycle to unblock `app.exec()` on region selection, right-click, and Escape (preventing `speak.sh` hangs). Added image preprocessing (2.5x Lanczos upscale, grayscale conversion, contrast boosting) and multi-PSM fallback (`--psm 6`, `--psm 3`, `--psm 11`) to accurately read fine screen text.
- **Compact Essentials HUD & Collapsible More Tools Drawer (`tts_hud.py`)**: Redesigned Floating HUD header by removing confusing status LED dot and truncated title snippet. Replaced with a prominent Speed Pill (`#speedPill`) on the left, clear mode badge, and essential controls (Play/Pause, Jump ±10s, Stop, Scrubber, Volume, Close). Moved secondary actions (`Enqueue`, `Transcript`, `Queue`, `OCR`, `Save MP3`, `Bookmark`, `Anki`, `Sleep`, `Settings`) into a collapsible **More Tools Drawer** toggled via the `...` button or <kbd>M</kbd> hotkey.
- **Configurable Chunk Sizing & Parallel Synthesis Tuning (`tts_text_processor.py`, `speak.sh`, `tts-settings.py`)**: Added `first_chunk_max` (default 140 chars) and `max_segment_chars` (default 280 chars) settings and CLI options (`--first-chunk-max`, `--max-segment-chars`). Priority-staggered synthesis starts chunk 0 with 0ms delay while subsequent chunks micro-stagger, ensuring near-instant time-to-first-sound.
- **AI Text Condenser / Summarizer Before Speech (`tts_text_processor.py`, `speak.sh --summarize`)**: Added `--summarize` flag leveraging local Ollama LLMs with automatic word-frequency extractive summarizer fallback when offline or unavailable.
- **Voice Clarity & Frequency Compensation EQ (`TTSSettingsStore`, `tts-settings.py`, `speak.sh`)**: Added vocal clarity equalizer preset (`--af="highpass=f=100,equalizer=f=3000:width_type=h:width=1000:g=3.5,acompressor"`) toggleable in Settings Studio to enhance speech intelligibility on laptop speakers.
- **Per-Application Speech Profiles (`speak.sh`, `app_rules.json`)**: Added support for application-specific voice, speed, and language rules mapped by X11 window class in `~/.config/tts_settings/app_rules.json`.
- **Audio Cache Checksum & Corrupt Header Verification (`tts_synth_worker.py`)**: Verifies audio stream magic headers (`ID3`, `RIFF`, sync bytes) and minimum byte thresholds before committing to cache, automatically pruning corrupt files.
- **Calibre eBook Library Direct Extractor (`tts_reader.py`, `speak.sh --calibre`)**: Added `--calibre` command to inspect, extract, and queue books directly from Calibre library directories.
- **Headless GitHub Actions CI Workflow (`.github/workflows/ci.yml`)**: Added headless CI pipeline with ShellCheck linting and Xvfb virtual framebuffer testing across Python 3.10-3.12.
- **Per-User `0700` Runtime Directory (`$XDG_RUNTIME_DIR/speak-aloud-$UID`)**: Isolated all IPC sockets (`mpv.sock`, `synth.sock`), lock files, queues, and segment work directories in `$XDG_RUNTIME_DIR/speak-aloud-$UID` (`0700`) with backward-compatible user-owned `/tmp` symlinks.
- **Persistent Async Synthesis Worker & Local Piper Neural Fallback (`tts_synth_worker.py`)**: Added a persistent UNIX-socket `asyncio` synthesis server inside `tts-daemon.py` (`synth.sock`) using `edge_tts.Communicate` in memory, with automatic fallback to local `piper-tts` ONNX neural models and `espeak-ng`.
- **Systemd User Service (`speak-aloud-daemon.service`)**: Added and enabled `~/.config/systemd/user/speak-aloud-daemon.service` with `Restart=on-failure`.
- **Interactive Sentence Transcript Drawer & HUD Hotkeys (`tts_hud.py`)**: Added a collapsible live Transcript drawer in `FloatingPlayerWindow` that highlights/auto-scrolls the active sentence and jumps on click, plus full keyboard hotkeys (`Space`, `←`/`→`, `[`/`]`, `T`, `Q`, `O`, `S`, `Esc`).
- **OCR Screen-Region & Image Speak Mode (`tts_ocr.py`, `speak.sh --ocr`)**: Added PyQt6 rubber-band screen-region capture and `--ocr-image` extraction via `tesseract`, accessible from CLI, Floating HUD, Tray menu, and Settings Studio.
- **Schema-Validated Atomic Settings & Pronunciation Lexicon (`TTSSettingsStore`, `lexicon.json`)**: Added strict schema validation, atomic `tempfile` + `os.replace` writes to `~/.config/tts_settings/settings.json`, and a customizable pronunciation dictionary (`kubectl`, `PyQt6`, `nginx`, etc.) with a GUI editor in `tts-settings.py`.
- **Floating On-Screen Player HUD (`tts_hud.py`, `tts-daemon.py`)**: Added an always-on-top, draggable dark-slate player popup inspired by `obsidian-edge-tts` (`FloatingPlayerUI`), featuring a unified cross-segment timeline seek bar, elapsed/total timecodes, Play/Pause/Replay, Jump `-10s`/`+10s`, Stop, live Speed selector pill (`0.75x`–`2.0x`), and one-click Save MP3.
- **Chunked Generation Progress (`ChunkedProgressUI`)**: Added real-time chunk synthesis progress bar and per-chunk status pills (`1 ✓`, `2 ⟳`, `3 ○`) backed by `/tmp/speak-aloud-work/manifest.json` and `seg_XXX.status`.
- **Playback Queue Manager (`QueueManagerUI`)**: Added a draggable companion Queue window and `speak.sh --queue` flag to enqueue selections, reorder items, loop, and auto-advance through queued passages.
- **Smart Markdown & Technical Text Processor (`tts_text_processor.py`)**: Added Markdown/frontmatter/URL/code filtering, math & comparison symbol speech conversion (`320 x 240` → `320 by 240`, `>=`, `<=`, `≈`), bullet list normalization, deterministic German detection (preventing false positives on English technical text), and fast-first-chunk splitting (~220 chars for `seg_000`).
- **Facelifted Settings & Studio GUI (`tts-settings.py`, `tts-settings.sh`)**: Replaced the YAD form with a 3-tab PyQt6 Studio Settings dialog featuring expanded voices, live Test Voice buttons, filter toggles, a Quick Speak & MP3 Export bench, and cache management.
- **Core Bug Fixes (`speak.sh`, `speak-stop.sh`)**: Fixed duplicate CLI parsing loop, fixed stray `fi` causing double playback in `--text` mode, normalized boolean config files (`TRUE`/`FALSE` vs `yes`/`no`), replaced slow `xdotool search` scans with 2ms `xprop WM_CLASS` lookup, and isolated daemon process group via `setsid`.
